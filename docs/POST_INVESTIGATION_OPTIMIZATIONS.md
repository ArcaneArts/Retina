# Post-investigation implementation goal

This tracks the implementation goal following the October 19 performance
investigation. It is separate from the completed earlier cycles in
`OPTIMIZATION_INTEGRATION_2026_10.md`. All implementation workstreams now have
a shipped result or a tested rejection. The [final integration report](POST_INVESTIGATION_INTEGRATION.md)
contains matched eight-caller measurements, current-source validation, explicit
deadline limitations, and the requirement-by-requirement audit.

| Workstream | Current disposition | Final disposition |
| --- | --- | --- |
| Decoration overhead and diagnostics | [Compact GPU continuations](COMPACT_GPU_CONTINUATIONS.md) reduce dense checkpoint retention and CPU replay, fix internal queue handoff, and add opt-in phase/fallback diagnostics. [Early group suspension](EARLY_DECORATION_SUSPENSION_TRIAL.md) was implemented and rejected. [Bounded ready batches](READY_DECORATION_BATCHES.md) with immutable substrate reuse improve matched eight-caller Terralith throughput 1.3–4.9% and are enabled only on Metal with eligible GPU vine programs. Forced batching without such programs regressed two-caller vanilla and is not the default. | Closed: selected scheduling is included in the final paired comparisons and exact ordered-plan validation. |
| Material and placement checks | Compiled immutable material sets and bounded sharing are implemented and measured; see [the report](MATERIAL_PREDICATE_OPTIMIZATION.md). Prepared material layouts, repeated-column reuse and biome membership were implemented/tested and [rejected](PREPARED_PLACEMENT_LOOKUP_TRIAL.md): microbenchmarks improved, complete workloads did not justify shipping them. Reproducible patches and negative results are retained. | Closed: compiled predicates ship; prepared lookup and predecoded evaluator trials have archived implementations and negative evidence. |
| Effective GPU decoration coverage | Exact vine handoff and fallback pass real-GPU tests. [Detailed diagnosis](VINE_GPU_FALLBACK_TRIAL.md) identifies the dense fixture's 48 supposed overflows as missing material reads. A guard-input prototype was implemented and rejected. [Immutable substrate reuse](READY_DECORATION_BATCHES.md) removes repeated packing/uploads from windowed scheduling while sharing the existing 64 MiB retention budget; shared arena identity handles interleaved regions and lost buffers. | Closed: current actual-Metal handoff, missing-input/overflow, bounded-cache and interleaving tests pass. |
| Optional LZ4 MCA codec | [Type-4 LZ4 output](MCA_COMPRESSION.md) is implemented with typed records, configuration, framing/checksums, promotion/repair compatibility, whole-pipeline measurements and Minecraft-reader validation. Zlib remains the default because LZ4 increases storage and whole-pipeline results vary. | Closed: both codecs pass Minecraft lifecycle tests; another full-height eight-caller LZ4 corpus matches 8,192 zlib NBT records. |
| NBT encoding | [Biome metadata reuse](NBT_BIOME_METADATA_TRIAL.md) was implemented, tested and rejected after full-pipeline comparison. [GPU section palettes](GPU_SECTION_PALETTES.md) reuse final-block uploads and classification, preserve exact packed data, and are enabled on Metal with CPU fallback. | Closed: final NBT worker time is approximately halved; 40,960 complete NBT comparisons and current save/promotion/lighting checks pass. |
| GPU final-section encoding and specialization | [GPU heightmaps](GPU_HEIGHTMAP_TRIAL.md) were implemented/tested and rejected after Terralith regressions. [GPU palettes and compact block output](GPU_SECTION_PALETTES.md) reduce NBT worker time about half and improve repeated eight-caller vanilla throughput 9–10%, with extra readback. [Predecoded placement evaluation](COMPILED_PLACEMENT_EVALUATION_TRIAL.md) was implemented/tested and rejected after repeated vanilla throughput regressions; complete plans and 24,576 full NBT comparisons match. | Closed: final comparison covers retained evaluator and Metal palette defaults, including extra readback and fallback costs. |
| Combined integration and documentation | Predicate/continuation/codec/palette/batching cycles have complete-region comparisons. Palette validation includes eight generation callers with two CPU workers, plus actual Minecraft mixed-codec promotion, repairs, edits and malformed-cache atomicity. Placement specialization has a documented rejection, and the ordered-plan harness now includes tick IDs. README and per-cycle evidence are updated. | Closed: final report and README distinguish vanilla +3.1–6.1% from inconclusive Terralith −2.4%/+4.2%; raw data, merged PR audit and test limitations are retained. |

Each cycle uses its own worktree and PR with squash auto-merge. Preserve unrelated
active worktrees, use local bounded checks, and do not launch the game or trigger
GitHub Actions. Isolated stage savings must not be reported as complete-generator
gains. Recheck current source and merged changes before each subsequent cycle.
